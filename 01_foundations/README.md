# Phase 1 — Foundations

Goal: build the base needed before real engineering/strategy work starts. No shortcuts here — this is what interview mental-math and probability gates actually test.

## Topics

- Probability & statistics rigor (not just descriptive stats — distributions, conditional probability, expectation, variance, stochastic thinking)
- Linear algebra (vectors, matrices, eigenvalues — used everywhere in factor models and later ML/stat-arb work)
- Daily mental math drilling
- C++ fundamentals: memory model, RAII, move semantics, references vs pointers — real mechanics, not just syntax

See `../Learnings/` for reading material on these topics with read-status tracking.

## Parallel track (runs alongside every phase, not just this one)

- Daily mental math (e.g. Zetamac: https://zetamac.com)
- Daily probability problems (Fifty Challenging Problems in Probability — see `../05_interview_prep/`)
