# 6. Order placement is sandbox-only

Status: Superseded in part by ADR 11 (sandbox as its own adapter). Sandbox-only still holds.

## Context

Letting an agent place real orders needs safeguards that don't exist yet: explicit opt-in, limits, confirmation flow.

## Decision

`BrokerPort.place_order` has a single path with a sandbox/live mode, and only sandbox is reachable. Live placement stays unimplemented until it has its own design and ADR.

## Consequences

Agents can exercise the full order path (validation, risk checks, events, notifications) without real money at stake.
