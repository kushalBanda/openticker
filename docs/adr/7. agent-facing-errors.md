# 7. Agent-fixable errors reach the agent; everything else stays opaque

Status: Accepted

## Context

The MCP Python SDK (2.x) withholds the text of any exception raised by a tool, except `ToolError`, sending only "Error executing tool <name>". An agent then can't tell an expired broker session from a mistyped symbol.

## Decision

- `ports/errors.py` defines `BrokerError` (and `BrokerSessionError`). Every broker adapter's errors derive from it, with messages that say how to recover.
- The MCP server translates a fixed set of errors to `ToolError`: `BrokerError`, `UnknownInstrumentError`, `UnknownBrokerError`, `BrokerConfigError`. It does so without naming any broker.
- Any other exception is treated as a crash: logged on the server, opaque to the client.

## Consequences

- Agents self-correct (reconnect, run `sync_instruments`, fix the symbol).
- An error meant for the agent must never carry secrets; adapter error messages include status codes and broker error bodies, never tokens.
