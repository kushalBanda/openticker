# 13. Live prices and what happens when they stop

Status: Accepted

## Context

Unattended exits need prices without an agent asking for them, so the daemon needs a streaming feed. Feeds drop. A risk engine that keeps deciding on prices it no longer receives is worse than one that stops.

## Decision

- **`MarketFeedPort`** streams ticks. The Zerodha adapter uses Kite's WebSocket ticker, reconnects with backoff and resubscribes on reconnect. Ticks update an in-memory latest-price cache read by sandbox execution and the strategy runner.
- **Each subscribed instrument is in one of three states:**
  - `live`: ticks are arriving.
  - `polling`: no tick for `STRATEGY_TICK_FALLBACK_SECONDS` (default 10). Batched REST quotes take over, backing off on rate limits. The stream subscription stays, and the next tick returns the instrument to `live`.
  - `stale`: neither source produced a price for `STRATEGY_TICK_STALE_SECONDS` (default 60).
- **A contract that isn't trading is not stale.** A quote still returns its last traded price, and that counts.
- **`stale` is terminal.** When any open leg goes stale, its strategy run stops with reason `tick_stale`, sends close orders for every open leg and notifies. It does not resume on its own; restarting is an explicit `start_strategy`. A risk engine that halted on bad prices must not quietly start again.
- In the sandbox those close orders fill on the first fresh price (ADR 11), so the stale instrument keeps being polled.
- **The market calendar is pure** (`core/calendar`): trading days, session hours and special sessions per exchange. It reads a holiday file shipped with each release, compiled from the exchanges' published circulars and overridable at `$OPENTICKER_HOME/holidays.json`. Nothing is scraped at runtime.

## Consequences

- A strategy never trades on prices it hasn't seen, and never makes up an exit price.
- A missed holiday in a stale holiday file shows up as orders failing loudly on a closed market, not as silent wrong behaviour.
- Tests run on a scripted fake feed and a fake clock, so none of this needs market hours to test.
