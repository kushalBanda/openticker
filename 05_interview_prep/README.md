# Phase 5 — Interview-specific prep

Goal: convert the technical base built in Phases 1-4 into interview-ready reflexes. This is not deferred to the end for drills — mental math and probability run parallel from Phase 1 onward. This phase is where books, mock interviews, and market-making games concentrate.

## Reading order

1. *A Practical Guide to Quantitative Finance Interviews* — Xinfeng Zhou ("Green Book")
2. *Heard on the Street* — Timothy Crack
3. *Fifty Challenging Problems in Probability* — Frederick Mosteller

## What these firms actually test (from research, cite sources in `../Learnings/`)

- Mental math — hard gate at Jane Street; well-credentialed candidates get rejected on this alone
- Probability under time pressure — e.g. Optiver: 10 probability questions, 90 seconds each
- Market intuition / game theory — real historical market events come up (2007 quant crisis, 2010 flash crash, 2020 oil futures collapse)
- Coding/algorithms — a separate bar from the brainteaser rounds, expects real competence

## Practice

- Mock interviews
- Market-making games
- Daily mental math (Zetamac) and probability drills, ongoing from Phase 1
